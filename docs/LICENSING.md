# Licensing and Reuse Boundary

This repository does not currently declare a repository-wide software or data
license. Absence of a license is not permission to copy, redistribute, execute,
or use any content for training.

The opaque source files are registered in `artifacts/manifest.json`. Their
current governance state is deliberately fail-closed:

- original filenames and external provenance are unresolved;
- sensitivity is `unknown`;
- license status is `unknown`;
- content SHA-256 values are recorded and independently recomputable;
- review status is `unreviewed`;
- `training_allowed` is `false`.

Git blob identities, SHA-256 values, and byte sizes preserve content identity,
but they do not establish authorship or legal rights. Each artifact must receive
explicit provenance, sensitivity, and license review before any downstream use.
Executable or formal source stored under an opaque extension must not be run
merely because its format has been identified.
