# CF-LM Corpus Pilot v0.01 — governed selection contract

## Status

**IMPLEMENTED — real-corpus run not yet executed**

Branch: `agent/cflm-corpus-pilot-v001`

This pilot creates the first deterministic governed Training-data view intended for direct CF-LM corpus exposure. It does not change the Research Database, does not change canonical admission decisions, and does not auto-admit anything.

## Eligibility boundary

A source training candidate is eligible only when all of the following are true:

- `admission.status == admitted`;
- task is `multi_turn_dialogue` for the frozen v0.01 pilot;
- the example is not personal by domain or scope;
- the source split is still `unassigned`;
- `split_group` is present;
- rendered input and target are both non-empty.

Existing train/validation/test/holdout assignments are never repurposed by this recipe.

## Frozen selection

Defaults:

```text
requested train records   = 128
requested holdout records = 32
minimum train records     = 32
minimum holdout records   = 8
```

Selection is by whole `split_group`, never by individual row. Groups are ordered by:

```text
sha256("CFLM-CORPUS-PILOT-V001-GROUP\0" + split_group)
```

The holdout is selected first. Training groups are selected only from the remaining groups. Because groups are indivisible, the actual record count may slightly exceed the requested count.

The selected train and holdout example IDs are content-addressed into a frozen `selection_sha256`. Reordering the source JSONL therefore does not change pilot membership.

## Output

`build_cflm_corpus_pilot_v001.py` writes:

```text
data/exports/cflm_corpus_pilot_v001/
  pilot_candidates.jsonl
  pilot_manifest.json
  packs/
    train.cflm
    validation.cflm
    test.cflm
    holdout.cflm
    records.jsonl
    manifest.json
```

The `.cflm` packs are generated by the existing governed teacher-data bridge. Only visible UTF-8 input and target bytes enter the pack. Reasoning is not consumed.

## Run

```shell
python3 build_cflm_corpus_pilot_v001.py \
  --candidates data/training_db/candidates.jsonl \
  --out-dir data/exports/cflm_corpus_pilot_v001
```

The script fails closed if the explicitly admitted eligible pool cannot satisfy the frozen minimum train/holdout sizes.

## Self-test

```shell
python3 _selftest_cflm_corpus_pilot_v001.py
```

The self-test checks deterministic selection, whole-group split separation, admission filtering, personal exclusion, source-order invariance, and round-trip generation of train and holdout CF-LM packs.

## Claim boundary

This layer establishes only a governed, deterministic corpus selection and pack-generation boundary. It does not establish successful CF-LM training, language competence, semantics, grammar induction, or holdout generalization.

The corresponding CF-LM branch is `agent/cf-lm-corpus-pilot-v001`, which evaluates the resulting packs under a first-order byte-relation boundary experiment.
