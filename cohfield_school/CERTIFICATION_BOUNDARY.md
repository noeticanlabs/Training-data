# NELS experimental learning and qualification boundary

## What exists

The source-only toy world is an interactive environment for learner-chosen
interventions, observation feedback and withheld same-world predictions.
A hash chain records each event, but has no independent witness or signature.
It tests the **environment mechanics**, not a learning capability.

## What is not established

- No CohField-native adapter is wired to this school.
- No actual CohField process has been taught, restarted or evaluated here.
- No temporal retention, interference or cross-world transfer has been tested.
- The test generator lives in openly readable source; its exams are unsuitable
  for independent competency certification.
- The receipts are not CohField learning evidence, H2 verification, or Class C
  authorization. The school cannot certify itself.

## Qualification gates for first real grade

Q0. Freeze both repository commit SHAs, native checkpoint and measurement plan.
Q1. Secure an adapter that sends only typed candidate experiences into CohField.
Q2. Record baseline performance on a source-family-separated held-out set.
Q3. Show an actual learned native-state update linked to authentic receipts.
Q4. Stop the CohField process, restore only its own state, and verify retention.
Q5. Measure cross-world transfer, wrong-rule refusal and old-skill regression.
Q6. Reconcile costs, revoke invalid evidence, simulate interrupted sessions.
Q7. Use a distinct examiner-controlled secret test generator unavailable to the
    learner and trainer; test for answer leakage, source overlap and leakage
    through Class B retrieval.
Q8. Independent verifier reviews exact-run artifacts and, if justified, signs a
    time- and scope-limited grade certificate.

Default outcome is NOT_CERTIFIED if *any* mandatory gate is missing. A
successful in-repository unit test can establish correctness of software
mechanics only, not scientific independence or acquired intelligence.

## CohField authority separation

Class A remains responsible for reasoning and learned applicability.
Class B remains read-only, demand-governed retrieval of eligible evidence.
Class C remains spending and authority enforcement, never delegated to school.
External teachers may propose instructional cases; they cannot mint signed
physical observations, execution grants, canonical state or verifier signatures.

## Curricula to explore after the adapter is demonstrated

- Relations, semantic roles and entity tracking (Copilot L6).
- Ambiguity and refusal of unsupported reference resolution (L7).
- Contextual carry-forward and contradictory context (L8).
- Native causal and action-consequence environments.
- Long-horizon retention and interference from unrelated skills.

No curriculum material is auto-admitted, and no personal-source exports are
copied from the existing local research database into public artifacts.
